  Liquid oxygen is attracted into the pole of a strong magnet, whereas liquid
  nitrogen is not.
  (d) Deduce, using molecular orbital theory, the origin of this difference.
answer: >-
  O2 has two unpaired electrons in degenerate pi*_2p orbitals (Hund's rule), so
  it is paramagnetic and is attracted into a magnetic field. N2 has all valence
  electrons paired in MOs, so it is diamagnetic and is not attracted.
mark_scheme: >-

  M2 unpaired electrons cause paramagnetism / attraction to field;
  M3 N2 has no unpaired electrons (all paired) so diamagnetic.
