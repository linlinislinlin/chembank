question_text: >-
  For copper, the unit-cell edge a = 361 pm and the density is 8.96 g cm-3.
  (c) Use these data to determine a value for the Avogadro constant.
answer: >-
  V = (361 x 10^-12 m)^3 = 4.70 x 10^-29 m^3 = 4.70 x 10^-23 cm^3.
  mass of one cell = 8.96 x 4.70 x 10^-23 = 4.21 x 10^-22 g.
  N_A = (4 x 63.5) / 4.21 x 10^-22 = 6.03 x 10^23 mol-1.
mark_scheme: >-

  M3 mass of cell = density x V; M4 N_A = 4 x Ar / mass of cell.
